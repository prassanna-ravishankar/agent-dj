# Agent DJ brand assets

The mark combines two independent decks with one uninterrupted horizon. The crossing is the
scheduled handoff; the continuous line represents the operating promise that music must not stop.

## Files

- `agent-dj-github-avatar-1024.png` — primary square avatar on the warm-black brand ground
- `agent-dj-mark-transparent-1024.png` — full-size amber mark with transparency
- `agent-dj-mark-transparent-512.png` — smaller transparent mark for general use
- `agent-dj-logo-imagegen-source.png` — original generated source, retained for future iterations

The production versions use only `#0E0D0C` and `#FFB454`, matching the web design tokens. Keep the
mark centered with its existing clear space. Do not add gradients, shadows, waveforms, or extra
colours.
